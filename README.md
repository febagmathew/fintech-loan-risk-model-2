## 📌 Project Overview

The **Fintech Loan Risk Model** interactive dashboard provides an intuitive visual interface for financial institutions and credit analysts to evaluate applicant risk. By combining client dataset parameters with front-end risk scoring calculations, this tool helps streamline credit decisioning and default probability assessment.

---

## ✨ Key Features

- **Interactive Risk Scoring:** Real-time evaluation of applicant data, loan amounts, and credit indicators via client-side calculations.
- **Dataset Integration:** Built-in parsing of financial records from `dataset.csv` to drive risk metrics.
- **Responsive Dashboard:** Modern UI styled for clean data readability across desktops and mobile devices.
- **Lightweight & Fast:** Runs entirely in the browser with zero external dependencies required.
